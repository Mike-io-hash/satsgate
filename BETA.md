# Beta Disclaimer

`satsgate` is currently in **beta**.

- APIs and behavior may change.
- There is no formal SLA.
- Use small amounts while testing.
- The hosted gate is live at `https://gate.satsgate.org` in closed beta. Sites are approved manually.

The terms for the hosted gate are in [`docs/hosted-gate-terms.md`](./docs/hosted-gate-terms.md). The public page is `https://satsgate.org/terms`.

If you find issues, please report them via GitHub Issues.
