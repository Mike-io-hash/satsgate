# Beta Disclaimer

`satsgate` is currently in **beta**.

- APIs and behavior may change.
- There is no formal SLA.
- Use small amounts while testing.
- The hosted gate (`https://gate.satsgate.org/<slug>/...`) is in this tree as its own container. It is not on the public internet until DNS exists and the Caddy site block is uncommented. New sites stay pending until an operator approves them.

If you find issues, please report them via GitHub Issues.
