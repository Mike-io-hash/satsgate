# Beta Disclaimer

`satsgate` is currently in **beta**.

- APIs and behavior may change.
- There is no formal SLA.
- Use small amounts while testing.
- The hosted gate (`https://gate.satsgate.org/<slug>/...`) is not live. Core 0.10.0 only stores the site registry. New sites stay pending until an operator approves them.

If you find issues, please report them via GitHub Issues.
